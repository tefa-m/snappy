# Security

Snappy is a personal project maintained on a best-effort basis; there are no
supported releases beyond the latest commit on `main`.

**Reporting a vulnerability:** please use GitHub's private reporting
(Security → "Report a vulnerability") instead of a public issue. I'll
acknowledge it as soon as I can, but there's no guaranteed response time.

Please don't attach real screenshots or recordings that contain personal data
to issues or reports; a synthetic example is enough.

In scope: anything that makes captured content (screenshots, OCR text,
recordings) reach a place the user didn't choose, and problems in the build or
install scripts (`scripts/`). Note that blur and pixelate are documented as
*not* being redaction (see the README).
