## Status (2026-07-19)

**MVP complete and fully verified.** All features (P1–P6) are implemented, the automated gate is green, and every feature's manual checklist has passed (last two — preview panel/pins and editor highlights — verified 2026-07-19).

**Frozen-screen capture (2026-08-25/26) — implemented, manual checklist pending.** Area capture now snapshots every display *before* activating, so a foreign context menu, menu-bar menu or tooltip survives into the shot; the selection is cropped from that snapshot. The overlay no longer greys the screen (only the selected region is tinted, and only once dragging starts) and no longer fades in and out (`animationBehavior = .none` — an `NSPanel` infers a utility-window fade), so the frozen screen reads as the live one. Fullscreen gained the ⇧⌘3 global hot key. Automated gate green (182 tests). Checklists in [`features/capture.md`](../features/capture.md) and [`features/preview-panel.md`](../features/preview-panel.md).

**Code-review fix pass (2026-10-08) — implemented, manual checklists pending.** Two independent reviews were triaged; 17 bugs and 6 optimisations landed (multiple editors coexist; text committed before export; crop drops outside annotations; no same-second Save overwrite; capture sessions can't overlap; shareable-content cache generation guard; Retina DPI; band-only background sampling + direct fill; effect cache; canvas growth cap; …). Automated gate green (204 tests, 0 warnings). Per-feature notes in each doc's 2026-10-08 log entry and "review pass" checklist: [`capture`](../features/capture.md), [`editor`](../features/editor.md), [`annotations`](../features/annotations.md), [`canvas-expansion`](../features/canvas-expansion.md), [`pin`](../features/pin.md), [`preview-panel`](../features/preview-panel.md), [`app-shell`](../features/app-shell.md).
